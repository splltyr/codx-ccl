1. Frontend Architecture & Design System

We engineered the web client on React 19 and Vite 8 with Tailwind CSS v4. Rather than using generic UI component libraries, we created a bespoke glassmorphic design system adhering strictly to the FEU Diliman cybernetic aesthetic.

Core Design System Tokens

  • Obsidian Base (#0a0414): Deep matte backdrop ensuring low eye fatigue and high contrast.
  • Tamaraw Gold (#FFD700): High-visibility primary accent honoring FEU Diliman institutional colors.
  • Royal Purple (#6D28D9 / #8B5CF6): Signature accent for interactive controls, cards, and buttons.
  • Backdrop Filtering: Standardized 24px frosted glass blur with hairline borders (rgba(255, 255, 255, 0.08)).

Scroll-Driven Spring Physics

Using Framer Motion spring solvers (damping: 26, stiffness: 90, mass: 0.55), the rocket launch sequence maps raw user scroll deltas smoothly into rocket camera ascent, celestial orbit receding, and the Dextron mascot reveal with zero jank.

2. Interactive HTML5 Canvas 2D Systems

We deliberately chose lightweight HTML5 Canvas 2D context engines over heavy DOM trees or WebGL shaders for rapid rendering and instant responsiveness.

A. Warp-Speed Constellation Starfield (CyberBackground.jsx)

  • Proximity Mesh: Dynamically calculates distance vectors between stars within 130px to render glowing constellation filaments.
  • Scroll Velocity Warp: Listens to window.scrollY and mouse wheel deltas to compute instantaneous acceleration. When the user scrolls, stars stretch downward into rapid warp streaks that decay with exponential deceleration (warpVelocity *= 0.92).
  • Interactive Cursor Tether: Magnetic field calculations draw energy lines from stars to cursor position with custom procedural hums.

B. Real-Time 1024×1024 PFP Frame Generator (PfpGenerator.jsx)

  • Interactive Pan & Drag: Direct pointer capture (setPointerCapture) enables mouse drag and mobile touch dragging with 1:1 screen-to-canvas coordinate mapping.
  • Scroll-to-Zoom: Intercepts canvas wheel events with non-passive listeners, scaling the photo between 0.5× and 3.0× without triggering browser page scrolling.
  • Pixel-Perfect HD Export: The offscreen 1024×1024 export canvas proportionally scales user pan offsets (exportScale = 1024 / 600) underneath official high-res PNG frame overlays.

3. Procedural Audio Synthesis via Native Web Audio API

To eliminate external audio hosting, bandwidth bottlenecks, and lag, all audio in CODX is synthesized programmatically at runtime using the browser's native AudioContext.

Sound Engine Architecture (audioSynth.js)

  • Lofi Lounge Chord Loop: Continuous four-chord progression in C# minor (C#m7 – Amaj7 – F#m7 – G#7) using dual triangle oscillators passed through a resonant Biquad lowpass filter (620Hz, Q: 1.8).
  • Haptic Click Feedback: 18ms exponential frequency pitch sweep (880Hz down to 220Hz) providing tactile feedback for button clicks.
  • Dextron Robot Voice: Formant-frequency modulated square wave chirps triggered procedurally during arrival sequences.
  • Zero Asset Dependency: Total audio payload footprint is 0 KB of media files.

4. Cloud Backend & Real-Time Firestore

CODX connects directly to Google Firebase Firestore and Firebase Authentication with dual-layer fallback to persistent local storage for disconnected environments.

Firestore Collections

  • /articles: Real-time event dispatches, workshop notices, and hackathon schedules.
  • /frames: Official transparent PNG frames uploaded by administrators for community PFP generation.
  • /tracks: Student technical committees and tracks populating registration dropdowns dynamically.
  • /applications: Student membership applications with approval, archiving, and review tools.

Discreet Council Admin Portal

Authenticated through Firebase Auth and accessible globally via Ctrl + Shift + A, granting executive officers real-time administrative oversight over public content.
